
# Captcha Example  

## 📖 Project Description  
**Captcha Example** is a simple web application that demonstrates how to create and validate a **Captcha** using **HTML, CSS, and JavaScript**. The Captcha helps verify that the user is human by requiring them to enter randomly generated text displayed on a noisy, distorted image.  

---

## ✨ Features
- 🖼️ **Captcha Display**: Random alphanumeric text is generated and rendered on a Canvas element.  
- 🔄 **Refresh Captcha**: Button to generate a new Captcha image instantly.  
- ✅ **Validation**: Compares user input with the generated Captcha text.  
- 🎨 **Noise & Lines**: Adds random dots and lines to make the Captcha harder for bots to read.  
- 🖌️ **Modern UI**: Clean and responsive design with styled inputs and buttons.  

---

## 🛠️ Technologies Used
- **HTML5** for structure  
- **CSS3** for styling  
- **JavaScript** for Captcha generation, rendering, and validation  

---

## 🚀 How to Use
1. Open the `index.html` file in a modern browser.  
2. A Captcha image will be generated automatically.  
3. Enter the Captcha text into the input field.  
4. Click **Submit** to validate or **Refresh Captcha** to generate a new one.
